# 🌿 나라장터 환경 입찰공고 실시간 스마트폰 알리미

나라장터(조달청)에 등록되는 **수질, 대기, 폐기물, 탄소중립, 태양광/신재생에너지, 소음진동, 환경영향평가** 등 환경 분야 신규 공고를 실시간으로 자동 감지하여, 사용자의 **핸드폰으로 즉시 소리/진동 푸시 알람**을 보내주는 시스템입니다.

---

## 📱 핸드폰 알림 1분 연동 가이드 (초간편 ntfy 푸시)

회원가입이나 API 키 발급 없이 스마트폰에서 1분 만에 바로 알람을 받을 수 있습니다.

1. **핸드폰 앱 설치**:
   - 안드로이드: Google Play 스토어에서 **`ntfy`** 검색 후 설치
   - 아이폰(iOS): App Store에서 **`ntfy`** 검색 후 설치
2. **알림 채널(Topic) 구독**:
   - 앱을 켜고 우측 상단 `+` 버튼을 누릅니다.
   - 토픽 이름에 `config.json`에 적힌 채널명 (예: `nara-env-alert-myphone`)을 입력하고 **구독(Subscribe)**을 누릅니다.
3. **완료!**:
   - 나라장터에 새로운 환경 공고가 올라오면 핸드폰 화면에 팝업 알람과 소리/진동이 울립니다.
   - 알림을 터치하면 **나라장터 상세 공고 화면으로 1초 만에 바로 연결**됩니다.

*(원하시는 경우 텔레그램 봇이나 디스코드 웹훅으로도 알림을 받을 수 있습니다)*

---

## 🚀 실행 방법

### 1. 웹 대시보드 실행 (공고 확인 및 설정 UI)
- `run_app.bat` 더블 클릭
- 브라우저(`http://localhost:8501`)에서 감지된 환경 공고 목록, 통계 확인, 즉시 알람 테스트, 키워드 추가/삭제 가능

### 2. 백그라운드 자동 수집 데몬 실행 (주기적 상시 모니터링)
- `run_daemon.bat` 더블 클릭
- 설정된 주기(기본 5분)마다 자동으로 나라장터 공고를 체크하여 신규 환경 공고 발생 시 즉각 핸드폰으로 알람을 쏩니다.

## 🔍 지원하는 환경 키워드 분야 (총 60+ 키워드)

- **수질 / 상하수도**: 수질, 하수, 정수, 폐수, 오수, 침출수, 하천정화, 수생태, 물순환, 지하수 등
- **대기 / 탄소중립**: 대기오염, 미세먼지, 악취, 온실가스, 탄소중립, 배출권, 기후위기, 질소산화물, VOCs 등
- **폐기물 / 자원순환**: 폐기물처리, 재활용, 소각, 매립, 슬러지, 순환골재, 폐배터리, 음식물류 등
- **토양 / 생태 / 환경영향평가**: 오염정화, 토양오염, 생태복원, 환경영향평가, 사후환경영향조사, 자연환경 등
- **에너지 / 친환경 / ESG**: 태양광, 신재생에너지, 풍력, 바이오가스, 친환경, ESG, RE100 등
- **소음 / 화학물질**: 소음진동, 방음벽, 유해화학물질, 석면, 환경보건 등

## 🔑 공공데이터포털(data.go.kr) OpenAPI 정식 연동 안내

- 공공데이터포털에서 **'조달청_나라장터 입찰공고정보서비스'**를 무료 신청하신 후, 발급받은 일반 인증키를 대시보드의 **[⚙️ 환경 키워드 및 API 설정]** 탭에 입력하시면 정부 공식 실시간 API로 즉시 전환됩니다.
- API 키가 없는 상태에서도 시스템 내장 데모/시뮬레이션 모드로 즉시 모든 기능을 체험 및 테스트하실 수 있습니다.
